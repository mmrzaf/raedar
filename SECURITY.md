# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button on the repository's Security tab. Do not open a public issue.

Include what you found, how to reproduce it, and the impact you expect. You will get an acknowledgement, and a fix or an explanation, as soon as possible.

## Supported versions

Security fixes are made for the latest release.

## Scope

How Raedar handles access, data and exposure is described in [docs/security.md](docs/security.md). Running the UI without an authentication middleware, or giving Raedar unfiltered access to the Docker socket, is an operator configuration issue rather than a vulnerability in Raedar, but reports that show how to make the safe setup easier are welcome.
